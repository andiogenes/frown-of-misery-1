Install Frown of Misery

Over USB-MIDI, from Chrome, Edge or another Chromium browser. Back to the page

This browser cannot install firmware. It needs Web MIDI with SysEx: open this page in Chrome, Edge, Opera, Brave or another Chromium browser on a computer, over https.
Log

  


  

    Before you start
    
    
      
  • This is an early development build. It has not yet been tested on a real FM-1. Installing firmware is at your own risk.
    • 
      
  • Connect the device with a USB data cable and close every other app or tab that uses MIDI (DAWs, editors, M-UPGRADE).
    • 
      
  • Do not unplug it or close this page while it writes (about a minute). If it is cut off, plug it back in and
        press Install again: the device stays in update mode and the write resumes.
    • 
      
  • If Frown does not start: hold OCT- while switching on, to reach the USB rescue, then install again.
    • 
      
  • To go back to any other firmware, or to M-VAVE's: the FM-1 Firmware Hub.
    •
